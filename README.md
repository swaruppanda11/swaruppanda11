## Selected work

**KMP Desktop Expansion — Intercontinental Exchange**
Production cross-platform app extended to macOS and Windows via Compose Multiplatform. Separate desktop and mobile UI codebases on a shared KMP core (Decompose, MVIKotlin, Ktor, SQLDelight).

**[CanaryGuard](https://github.com/swaruppanda11) — Kubernetes Delivery Operator**
SLO-based canary rollback controller polling Prometheus for dual-signal health (HTTP 5xx + pod restarts), triggering automated rollback within 90 seconds of breach. End-to-end observability stack with OTel tracing, Loki, Jaeger, and 4 Grafana dashboards. Published at ETCOM 2025.

**ResilientP2P — Hybrid P2P Web Cache**
Hybrid P2P caching on a 12-pod GKE cluster using Kademlia DHT + centralized coordinator, achieving 67–90% external bandwidth reduction. Peer-auth layer with 3-mode rollout gating across 13 FastAPI endpoints. Reputation tracker detecting malicious peers in under 1 second; validated by 21 pytest tests and bash E2E scripts.

**EasyWrite**
iPad handwriting learning app for children — Apple Pencil, CoreML, SwiftUI. From Apple's iOS Developer Training Program (top 50 of 750 applicants).

**ParkValet**
Smart parking platform with AR navigation and AI camera enforcement. KMP multi-repo stack. CU entrepreneurship validation pipeline.
